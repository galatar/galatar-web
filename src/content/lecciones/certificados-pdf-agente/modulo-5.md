## Ahora sí: qué hace cada parte

El agente ha escrito el programa tan deprisa que es fácil no haberlo mirado. Antes de usarlo con datos reales, entiéndelo:

```text
Explícame generar.py por bloques, de arriba abajo.
Soy principiante: para cada bloque, qué hace en una o dos frases
y qué tendría que cambiar si quisiera modificarlo.
Añade al programa los comentarios que falten para que
yo pueda entenderlo sin ti dentro de seis meses.
```

Después haz **tú** un cambio pequeño, sin el agente: el tamaño de letra del nombre o una frase del texto. Ábrelo en un editor, cámbialo y ejecútalo en la terminal:

```bash
python generar.py
```

Si no sabes cómo ejecutarlo fuera del agente, pídeselo: «Explícame cómo ejecutar generar.py yo solo desde la terminal, con el entorno virtual». Vas a necesitarlo en el paso siguiente.

## Usarlo con datos reales, sin el agente

La regla de oro del módulo 1 se cumple aquí. El agente ha visto el programa y los datos inventados. **La hoja real no la va a leer.**

1. **Cierra el agente** o, como mínimo, cierra la conversación con esta carpeta.
2. **Copia la hoja real** a la carpeta como `asistentes.xlsx`.
3. **Ejecuta tú el programa** en la terminal.
4. **Si sale un error,** vuelve a poner el Excel de prueba antes de abrir el agente y cuéntale el error cambiando cualquier dato personal por uno inventado.
5. **Revisa tres certificados** antes de enviar ninguno y **borra la hoja real** de la carpeta cuando termines.

## Chat o agente: qué has visto

Si has hecho los dos talleres, compara tu experiencia con esta tabla:

| | Chat gratuito | Agente |
|---|---|---|
| Lo que haces tú | Copiar, pegar, ejecutar, guardar versiones | Aprobar, revisar, decidir |
| Velocidad | Lenta: cada vuelta pasa por ti | Rápida: prueba y corrige solo |
| Lo que aprendes por el camino | Mucho: tocas cada archivo | Menos, si no le pides que te explique |
| Memoria del proyecto | La conversación, que se pierde | El archivo de instrucciones |
| Riesgo | Pegar datos reales sin querer | Que lea archivos que no debía |
| Coste | Gratis | Casi siempre de pago |

No hay un ganador. El chat es ideal para empezar y entender. El agente compensa cuando ya sabes qué quieres y tienes muchas tareas que automatizar.

## ¿Y ahora qué?

La carpeta que has montado sirve de modelo para cualquier tarea repetitiva: cartas, justificantes, fichas o etiquetas. Copia la estructura, reescribe el archivo de instrucciones y pide el nuevo programa. La receta es siempre la misma: una hoja con una fila por documento, una plantilla y un programa que las une.
